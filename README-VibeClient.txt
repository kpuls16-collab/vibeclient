# Vibe Client — original mod bundle

This archive contains the three uploaded JAR files copied **byte-for-byte** into `mods/`.
No classes, modules, metadata, or GUI code inside those JARs have been changed.

## Included
- `mods/meteor-client-26.1.2-15.jar` — Meteor Client 26.1.2-15
- `mods/glazed-26.1.2-n-17.1.jar` — Glazed addon 26.1.2-n-17.1
- `mods/baritone-meteor-26.1.jar` — Baritone for Minecraft 26.1.2

## Compatibility
The uploaded metadata indicates Minecraft 26.1.2. Meteor requires Java 25 or newer; use a compatible Fabric Loader and Fabric API installation.

## Important
This is a preservation bundle, **not yet the modified Vibe Client GUI**. The original modules remain intact because the JARs are unchanged. A real GUI-only modification needs the matching Meteor source project (or permission and source for the relevant components) so the ClickGUI can be changed and rebuilt without stripping modules. The Glazed JAR declares `All Rights Reserved`, so it is included unchanged and is not repackaged or renamed internally.
